# Week 1: Introduction to Linux (Modules 1–3)

## What is Linux?
Linux is an operating system that started as a hobby project by Linus Torvalds. 
It was built similarly to Unix, but unlike Unix, Linux is free and open source ,
meaning anyone can access the source code, modify it, and adapt it to their needs.

Linux can be used through two interfaces:
- **GUI** (Graphical User Interface)
- **CLI** (Command Line Interface)

System administrators mostly use the CLI, since it's faster and more efficient 
than navigating through a GUI.

## Kernel vs. Operating System
The kernel and the operating system are often confused, but they're not the same thing:
- The **kernel** is like the engine of a car — it handles communication with 
  hardware components.
- The **operating system** is the entire car — the kernel plus all the tools, 
  utilities, and interfaces that make the system usable.

## Linux Distributions
A **distribution** (distro) is a specific version of Linux, packaged with its own 
tools and configurations. Examples include:
- Fedora
- Linux Mint
- Raspberry Pi OS

The distribution you choose depends on what you need your system to do.

## Where Linux Is Used
Linux powers a huge range of systems, including:
- Android (mobile devices)
- Embedded systems — systems built into devices to perform one specific task
- Servers, including web servers, database servers, and email servers

## Linux and Programming
Linux was built closely in line with the C programming language, which makes it 
very friendly for development work. It's also widely valued for the security it 
offers for everyday internet use.

## Package Managers
Linux uses **package managers** to install and manage software. One example is 
`rpm` (Red Hat Package Manager), which handles installing, updating, and removing 
`.rpm` packages on RPM-based distributions (like Fedora).
